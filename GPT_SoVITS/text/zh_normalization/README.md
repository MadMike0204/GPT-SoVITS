# 中文文本规范化

将数字、日期、金额等非标准文本转换为可朗读的中文，供中文 TTS 前端使用。
下表是规则示例；实际读法还取决于上下文和规则匹配。

| 类型 | 原文 | 规范化结果 |
| --- | --- | --- |
| 编号 | 陈永仁的编号27149 | 陈永仁的编号二七一四九 |
| 数值 | 黄金重达324.75克 | 黄金重达三百二十四点七五克 |
| 数值范围 | 12\~23；-1.5\~2 | 十二到二十三；负一点五到二 |
| 日期 | 1995年3月1日 | 一九九五年三月一日 |
| 时间 | 请在12:05通知我 | 请在十二点零五分通知我 |
| 温度 | 最低气温达到-10°C | 最低气温达到零下十度 |
| 分数 | 7/12的观众 | 十二分之七的观众 |
| 百分比 | 有62％的概率降雨 | 有百分之六十二的概率降雨 |
| 金额 | 12块5，34.5元，20.1万 | 十二块五，三十四点五元，二十点一万 |
| 电话 | 0421-33441122；+86 18544139121 | 零四二一三三四四一一二二；八六一八五四四一三九一二一 |

实现来源：[PaddleSpeech 中文规范化](https://github.com/PaddlePaddle/PaddleSpeech/tree/develop/paddlespeech/t2s/frontend/zh_normalization)，
原始参考：[DeepSpeech PR #658](https://github.com/PaddlePaddle/DeepSpeech/pull/658/files)。
